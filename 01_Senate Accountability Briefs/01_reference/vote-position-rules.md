# Vote-position rules

How to fill `[VOTE POSITION]` for a senator record.

## Default rule (party bloc)

- **Labor / Coalition (LP, NATS, LNP) / One Nation** → `Expected [Party] support, subject to confirmation` (these hold the ~61 votes expected to pass the bill)
- **Greens** → `Expected opposition`
- **Everyone else (Independents, other minor parties)** → `Unknown`

## Known overrides (beat the default rule)

A specific declared position always beats the party-bloc default. Check this list before applying the default rule above.

| Senator | Position | Source |
|---|---|---|
| David Pocock | Expected No | Dissenting report, Community Affairs committee final report, Aug 2026 — *"it is my understanding this Bill will pass... I cannot support it in its current form"* |
| Jordon Steele-John | Expected No | Greens dissenting report, Community Affairs committee final report, Aug 2026 — *"will be strongly opposing this Bill"* |

New overrides go here as they're found (e.g. from committee reports, public statements) — add a row, cite the source, and note it in the senator's `record.md`.

## Fixed immediate ask

Used for every senator regardless of vote position, unless a specific brief calls for something different:

> Require safeguards, transparent monitoring and a public implementation accountability mechanism before the vote
