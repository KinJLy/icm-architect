# Portfolio relevance check

Do this for every senator — don't default to skipping it.

A portfolio only earns the accountability-lens block in the brief if it has a **substantive link to how the Bill causes harm**, not just because the senator holds a title. Gallagher's brief used "Minister for Women" because the bill's SCCP cuts foreseeably shift unpaid care onto women — that's her actual policy responsibility, not a coincidence. A portfolio like "Minister for Trade" wouldn't earn a lens.

## Portfolios that would earn a lens (not exhaustive)

| Portfolio | Why it's relevant |
|---|---|
| Women | SCCP cuts foreseeably shift unpaid care onto women (used for Gallagher) |
| NDIS / Disability | Direct ownership of the scheme being amended |
| Health / Ageing | Flow-on costs to hospitals and the health system from reduced supports |
| Social Services / Government Services | Administration of the affected payments/services |
| Finance / Treasury | Owns the "savings vs. cost-shifting" budget tradeoff argument |
| Indigenous Australians | First Nations participants are a named equity cohort in the impact data |
| Regional Australia / Regional Health | Regional service-availability risk is a named concern in the brief |
| Aged Care | Same automated-decision-making and functional-assessment mechanisms recur in aged care policy |

## How to apply it

1. Look up the senator's current ministerial/shadow portfolio. Start from [senator-portfolios.md](senator-portfolios.md) — but that's a dated snapshot (2026-08-14); portfolios change unexpectedly, so confirm against a live source rather than trusting the snapshot alone, especially if it's been a while since the snapshot date. Use the [APH Parliamentarian Search](https://www.aph.gov.au/Senators_and_Members/Parliamentarian_Search_Results?&q=&sen=1&par=-1&gen=0&ps=96&st=1) (filtered to current senators) to check or re-derive the whole snapshot table.
2. Check it against the table above (or a clearly analogous portfolio).
3. If relevant: fill `[PORTFOLIO/MINISTERIAL ROLE]` and write the accountability-lens block with the **specific mechanism** connecting that portfolio to the bill's harms — mirror how the Women lens ties SCCP cuts to unpaid care, not a generic paragraph.
4. If not relevant (or no portfolio): omit `[PORTFOLIO/MINISTERIAL ROLE]` and delete the whole accountability-lens section from the brief.
