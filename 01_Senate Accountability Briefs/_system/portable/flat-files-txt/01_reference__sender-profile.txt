# Sender profile

Factory config — the same identity is used to sign every brief, read once by `_system/tools/finalize_send_pack.py` at the send-prep stage. Fill in the three fields above before finalizing any brief:

- `name` → fills `[YOUR NAME]` (sign-off, personal-note heading, footer)
- `role` → fills `[YOUR ROLE/TITLE]`
- `email` → fills `[YOUR EMAIL]` (sign-off, footer)

These are the same values used across all 76 senators — this isn't a per-senator field, so it lives here rather than in each record.
