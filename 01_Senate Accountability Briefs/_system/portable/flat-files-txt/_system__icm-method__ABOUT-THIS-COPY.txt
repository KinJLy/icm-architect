# About this copy

This is a local copy of the ICM method this workspace is built on (SKILL.md, README.md, `references/core.md`, `references/forms.md`, `assets/templates/*`) — the same files that live at the repo root, one level up from `01_Senate Accountability Briefs/`.

## Why a copy lives here

Per the method's own rule — *"method and instance live apart"* — this deployment shouldn't have to reach outside its own folder to understand or evolve the structure it's built on. Keeping a copy here means:

- This folder is self-contained: if it's ever zipped up, shared with a volunteer, or moved to another repo, the method that explains its own structure travels with it.
- This deployment's structure can evolve independently. If something about the Record library form needs adapting specifically for a senator-outreach campaign (as opposed to the generic method), that adaptation happens here, not by editing the shared root copy that other ICM deployments might depend on.

## Relationship to the root copy

This copy is **frozen at the point it was pulled** — it does not automatically update if `../../SKILL.md` or `../../references/*.md` change upstream. If you make a real improvement to the method while working in this deployment (not just a one-off local hack), consider whether it should also go back into the root copy so other ICM deployments benefit — but that's a deliberate choice, not something that happens by default.
